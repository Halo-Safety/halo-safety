# Halo 🦺
**Nobody should get hit by a machine they never saw coming.**

Halo is a worker-safety system that warns ground workers *and* equipment
operators the moment a worker enters a machine's blind zone — and logs
every near-miss so sites can fix the danger before someone gets hurt.

Theme: Construction & Manufacturing · natHacks 2026

## The problem
On construction sites, being struck by moving equipment is a leading cause
of death. The operator can't see the worker in their blind spot, and the
usual backup beeper only warns the operator — not the worker on the ground.
(NIOSH: ground-worker struck-by = ~73% of transportation-related work-zone
fatalities; about half happen when a vehicle is backing up.)

## What it does
- Each **worker** wears a tag; each **machine** carries a beacon.
- When a worker enters a machine's danger zone, BOTH are warned in <100 ms:
  the worker's tag **vibrates**, the operator's cab unit **buzzes + flashes**.
- A **dashboard** logs every close call (worker, machine, distance, time)
  for the site safety officer.

## Why it's different
- **Worker-specific** — only tagged people trigger it, not piles of material.
- **No GPS, no internet** — devices talk directly over radio; works anywhere.
- **Edge decision** — the alert fires on the device, instantly, fail-safe.
- **Grounded zones** — blind sectors come from NIOSH's measured blind-area
  diagrams, not guesses.
- **Data, not just noise** — near-miss logs turn a gadget into a safety system.

## How it works
1. All devices broadcast a short radio heartbeat (ESP-NOW / BLE).
2. Each tag reads signal strength (RSSI) → smoothed → distance estimate.
3. Multiple anchors on the machine give a rough **sector** (front/back/side).
4. An IMU tells us when the machine is **moving/reversing**.
5. Alarm fires only when: in danger radius AND in a blind sector AND machine
   is moving — with filtering + hysteresis so it doesn't false-alarm.

## Scope (tiered)
- **MVP:** 2 devices, proximity alert, two-way buzz + dashboard log.
- **Stretch:** sector detection + machine-motion logic + live dashboard.
- **Production path:** swap RSSI for UWB (10–30 cm ranging).

## Hardware
2–4× ESP32, 1× vibration motor, 1× buzzer + LED, 1× IMU (MPU6050),
breadboard + wires. Falls back to phones if hardware is short.

## Tech stack
ESP32 (Arduino/C++) · ESP-NOW/BLE · Python + Flask/WebSocket dashboard
